# Exercise

Give a practical exercise for the current topic matched to the student's level.

## Usage

```
/exercise
```

## Behavior

1. Get current topic from `CURRENT.md` and level/language from `me.md` — skip the reads if they're already in context this session
3. Generate one focused exercise appropriate for the topic and level
4. State clearly: what to do, what to submit, and what "good" looks like
5. Wait for the student's answer — do not give hints unprompted
6. After submission, use `/check` to review

## Exercise Format

```
**Exercise: <title>**

<Scenario or prompt — 2–4 sentences>

**Your task:**
1. <Step or deliverable>
2. <Step or deliverable>

**Submit:** <what to write or draw below>
```

## Notes

- One exercise per topic — not a list of drills
- Use real-world scenarios from apps in `me.md` when possible
- Adjust complexity to level: level 3 = guided steps, level 7 = open-ended design

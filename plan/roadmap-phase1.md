# Roadmap — Phase 1 (Foundations)
> Goal: Go from zero to building and deploying interactive web pages with vanilla JavaScript

> This phase assumes **no prior knowledge**. If you've never written code, you're in the right place.
> Frontend/full-stack devs: skim or skip per the entry point table in `roadmap.md`.

**Phase 1 Final Project:** Build an interactive app with vanilla JavaScript — no framework — that fetches data from a public API, renders it to the DOM, and lets the user filter or interact with it (e.g. a weather widget, a movie search, a todo list with persistence). Deploy it and write a short README explaining how it works.

> **Why vanilla JS before React?** React hides a lot of machinery. If you learn React without understanding the DOM, events, and async JavaScript underneath, you'll be stuck the moment something breaks outside React's happy path. Earn the framework.

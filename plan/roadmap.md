## Before You Start — Self-Assessment

Answer these six questions so the mentor can find your entry point:

1. Can you write a function in any language and explain variables, loops, and conditionals?
2. Can you build a basic web page with HTML and style it with CSS?
3. Have you built anything with a frontend framework (React, Vue, Angular)?
4. Have you built a backend API and connected it to a database?
5. Have you deployed a full application (frontend + backend + DB) anywhere?
6. Have you designed a system's architecture or led a technical decision?

> Type your answers in the chat. The mentor will mark which phases to **skip**, **skim**, or **go deep** on.

### Absolute Beginner Check
> If you answered "no" to question 1, you start at the very beginning — Module 01.

That's fine. This roadmap is designed to take someone who has never written code to a senior full-stack level. Phase 1 assumes zero prior knowledge. Do not skip it.

## Adaptive Entry Points

| Your Background | P1 (1-3) | P2 (4-7) | P3 (8-12) | P4 (13-15) | P5 (16-18) |
|---|---|---|---|---|---|
| Absolute beginner / Career switcher | Full | Full | Full | Full | Full |
| Knows programming, new to web | Skim | Full | Full | Full | Full |
| Frontend developer | Skip¹ | Skim | Full | Full | Full |
| Backend developer | Skim² | Full | Skim | Full | Full |
| Full-stack (junior, 1-2 yrs) | Skip¹ | Skim | Skim | Full | Full |
| Full-stack (mid, 3-5 yrs) | Skip¹ | Skip¹ | Skim | Skim | Full |

> ¹ **Skip** — do the milestone assessment only. If you pass, move on immediately.
> ² **Skim** — move fast, you know most of this already. Do the exercise, but don't dwell.
> **Full** — work through every topic and exercise.

> Frontend devs: skim Phase 1 but **don't skip the HTTP/Git topics** if those are shaky.
> Backend devs: skim Phase 1, but **build the React app in Phase 2** — it's where your blind spots are.

## Overview Timeline

```
Phase 1: Foundations            — the web, HTML/CSS, JavaScript
Phase 2: Frontend Development   — TypeScript, React, data/state, testing
Phase 3: Backend Development    — Node/Express, databases, auth, APIs, testing
Phase 4: Full-Stack & DevOps    — integration, Docker/CI-CD, performance
Phase 5: Senior Level           — system design, engineering practices, capstone
```

> Pace is up to you. At 3–5 sessions/week, a motivated beginner typically reaches the capstone in 10–14 months. Skill, not time, unlocks the next phase.

## The Stack You'll Learn

| Layer | Tools |
|-------|-------|
| Language | JavaScript → TypeScript |
| Frontend | React (Vite), React Router, TanStack Query, Tailwind |
| Backend | Node.js, Express (+ Nest concepts), TypeScript |
| Database | PostgreSQL + Prisma |
| Full-stack | Next.js |
| DevOps | Docker, GitHub Actions (CI/CD), a cloud host |
| Quality | Vitest, React Testing Library, Playwright |

> Concepts transfer to any stack. We pick one concrete stack so you actually ship, instead of drowning in choices.

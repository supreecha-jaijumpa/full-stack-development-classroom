# 7.2 Unit Testing (Vitest)

> Module 07 — Frontend Testing & Quality · Phase 2

**What you'll learn:** How to write and run fast, isolated unit tests for pure logic using Vitest.

- Setting up Vitest in a Vite + TypeScript project.
- Test structure: `describe`, `it`/`test`, and `expect` matchers.
- Testing pure functions, reducers, and utilities, including edge cases.
- Setup/teardown with `beforeEach`/`afterEach`.
- Mocking modules and functions with `vi.fn()` and `vi.mock()`.
- Running tests, watch mode, and reading coverage reports.

**Hands-on:** Write Vitest tests for a pure utility or reducer from your dashboard, covering normal and edge-case inputs.
**You can move on when:** You can write passing unit tests with meaningful assertions and run them in watch mode while refactoring.

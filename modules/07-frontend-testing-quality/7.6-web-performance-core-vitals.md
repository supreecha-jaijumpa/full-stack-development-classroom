# 7.6 Web Performance & Core Web Vitals

> Module 07 — Frontend Testing & Quality · Phase 2

**What you'll learn:** How to measure real-world web performance and improve the metrics that affect users and search ranking.

- The Core Web Vitals: LCP, INP, and CLS, and what each measures.
- Measuring with Lighthouse, the Performance panel, and field vs. lab data.
- Reducing bundle size: code splitting, tree-shaking, and analyzing the bundle.
- Optimizing images, fonts, and loading order.
- Caching, lazy-loading, and minimizing render-blocking resources.
- Setting performance budgets and tracking regressions.

**Hands-on:** Run Lighthouse on your dashboard, record the Core Web Vitals, then make one change that measurably improves a metric.
**You can move on when:** You can interpret a Lighthouse report and demonstrate a before/after improvement in a Core Web Vital.

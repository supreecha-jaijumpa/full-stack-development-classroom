# 7.4 E2E Testing (Playwright)

> Module 07 — Frontend Testing & Quality · Phase 2

**What you'll learn:** How to test complete user flows in a real browser with Playwright.

- What end-to-end tests cover and why they sit at the top of the pyramid.
- Installing and configuring Playwright in the project.
- Locators, actions, and web-first assertions that auto-wait.
- Writing a test for a multi-step user journey across pages.
- Handling navigation, network, and authentication state.
- Running headed vs. headless, debugging with the trace viewer, and CI integration.

**Hands-on:** Write a Playwright test for one critical flow, e.g. browse a product, add it to the cart, and reach checkout.
**You can move on when:** You can author and run a reliable E2E test for a real user journey that passes headless.

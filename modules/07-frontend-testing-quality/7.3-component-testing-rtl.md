# 7.3 Component Testing (React Testing Library)

> Module 07 — Frontend Testing & Quality · Phase 2

**What you'll learn:** How to test React components the way users actually interact with them, using React Testing Library.

- The RTL philosophy: query by accessible role/label/text, not implementation.
- Rendering components and querying with `getBy`/`findBy`/`queryBy`.
- Simulating user interaction with `user-event` (typing, clicking).
- Asserting on the DOM with `jest-dom` matchers.
- Testing async UI with `findBy` and `waitFor`.
- Mocking network requests (e.g. with MSW) for component tests.

**Hands-on:** Write RTL tests for a form component, asserting on labels/roles and simulating typing and submission.
**You can move on when:** You can test a component through its accessible interface and avoid asserting on internal state or class names.

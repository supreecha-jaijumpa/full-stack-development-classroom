# 5.5 Lists & Conditional Rendering

> Module 05 — React Fundamentals · Phase 2

**What you'll learn:** How to render dynamic collections and show or hide UI based on state.

- Rendering arrays with `.map()` to produce lists of elements.
- The `key` prop: why it matters and choosing stable keys (not array index).
- Conditional rendering with `&&`, ternaries, and early returns.
- Handling empty states and "no results" messaging.
- Filtering and sorting data before rendering.
- Keeping list-item components small and typed.

**Hands-on:** Render a filterable list of items with stable keys and a friendly empty-state message when no items match.
**You can move on when:** You can render a filtered list with correct keys and toggle between content and an empty state cleanly.

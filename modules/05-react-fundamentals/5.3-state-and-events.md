# 5.3 State & Events

> Module 05 — React Fundamentals · Phase 2

**What you'll learn:** How to make components interactive by holding state and responding to user events.

- What state is and how it differs from props.
- Handling events: `onClick`, `onChange`, `onSubmit`, and the synthetic event.
- Typing event handlers in TypeScript (e.g. `React.ChangeEvent<HTMLInputElement>`).
- Controlled inputs: binding form fields to state.
- State updates are asynchronous and trigger re-renders.
- Lifting state up to share it between sibling components.

**Hands-on:** Build a counter with increment/reset buttons and a controlled text input that echoes its value.
**You can move on when:** You can wire a form input to state and lift that state to a parent so a sibling can read it.

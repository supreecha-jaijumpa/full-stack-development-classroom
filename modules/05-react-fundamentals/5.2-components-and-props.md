# 5.2 Components & Props

> Module 05 — React Fundamentals · Phase 2

**What you'll learn:** How to break a UI into reusable components and pass data into them with typed props.

- Defining function components and composing them into a tree.
- Passing props and reading them; props are read-only (one-way data flow).
- Typing props with a TypeScript `interface` or `type`.
- The `children` prop and composition over configuration.
- Default values and optional props.
- Splitting a screen into small, single-responsibility components.

**Hands-on:** Build a typed `<Card title icon>` component and render several instances with different props.
**You can move on when:** You can design a typed prop interface for a component and reuse that component in two places without duplication.

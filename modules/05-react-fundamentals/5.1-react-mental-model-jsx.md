# 5.1 React Mental Model & JSX

> Module 05 — React Fundamentals · Phase 2

**What you'll learn:** How React's declarative, component-based model works and how to write JSX that describes your UI.

- The declarative idea: UI as a function of state, not manual DOM manipulation.
- JSX syntax: expressions in `{}`, attributes, and the single-root rule (fragments).
- How JSX compiles to `React.createElement` and what the virtual DOM does.
- Components as functions returning JSX; PascalCase naming.
- Rendering a root with `createRoot` and mounting into the DOM.
- Differences from HTML: `className`, `htmlFor`, and camelCase event props.

**Hands-on:** Render a small static layout as JSX from a root component and view it via the Vite dev server.
**You can move on when:** You can convert a block of HTML to valid JSX and explain why React re-renders when state changes.

# 5.4 Hooks — useState & useEffect

> Module 05 — React Fundamentals · Phase 2

**What you'll learn:** The two foundational hooks for managing state and side effects in function components.

- `useState`: declaring state, the setter, and functional updates.
- Typing state with generics (`useState<User | null>(null)`).
- `useEffect`: running side effects after render (fetching, subscriptions, timers).
- The dependency array and how it controls when effects re-run.
- Cleanup functions and avoiding leaks (intervals, listeners, aborted fetches).
- The Rules of Hooks: call at the top level, only in components/custom hooks.

**Hands-on:** Build a component that fetches data in `useEffect` on mount and renders loading and loaded states.
**You can move on when:** You can explain what an empty vs. populated dependency array does and write a cleanup function that runs correctly.

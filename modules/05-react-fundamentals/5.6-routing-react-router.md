# 5.6 Routing (React Router)

> Module 05 — React Fundamentals · Phase 2

**What you'll learn:** How to turn a single React app into a multi-page experience with client-side routing.

- Why SPAs need a router and how client-side navigation differs from full page loads.
- Setting up `BrowserRouter`, `Routes`, and `Route`.
- Navigation with `<Link>` and `<NavLink>` (and programmatic `useNavigate`).
- Dynamic route segments and reading params with `useParams`.
- Nested routes and shared layouts with `<Outlet>`.
- Handling unknown routes with a 404 / catch-all route.

**Hands-on:** Add home, list, and detail routes to your app, where the detail page reads an `:id` URL parameter.
**You can move on when:** You can navigate between pages without a full reload and load a detail page directly from its URL.

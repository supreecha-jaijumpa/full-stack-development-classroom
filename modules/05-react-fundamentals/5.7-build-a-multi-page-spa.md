# 5.7 Build a Multi-Page SPA (hands-on)

> Module 05 — React Fundamentals · Phase 2

**What you'll learn:** How to combine components, state, hooks, and routing into a complete multi-page application.

- Planning the component tree and routes before coding.
- Sharing state across pages (e.g. a cart) by lifting it to a common ancestor.
- Building reusable, typed presentation components.
- Loading data with `useEffect` and reflecting loading/empty states.
- Navigating between list and detail views with React Router.
- Organizing files into a sensible folder structure.

**Hands-on:** Build a product catalog SPA: a list page, a detail page, and a cart whose state is shared across routes.
**You can move on when:** Your SPA navigates between at least three routes, shares cart state across them, and uses only typed, reusable components.

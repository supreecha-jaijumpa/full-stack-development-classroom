# 10.7 Secure API Practices

> Module 10 — Authentication & Security · Phase 3

**What you'll learn:** Practical defaults that harden an API against common attacks.

- Security headers (Helmet) and HTTPS/TLS everywhere
- Rate limiting, throttling, and brute-force protection
- Strict CORS configuration
- Input hardening and output encoding
- Secret management and avoiding secret leakage in logs
- Dependency auditing and keeping packages patched

**Hands-on:** Add security headers, rate limiting, and tightened CORS to your API and verify them.
**You can move on when:** Your API ships secure-by-default headers, limits abusive traffic, and restricts origins.

# 10.2 Sessions vs JWT

> Module 10 — Authentication & Security · Phase 3

**What you'll learn:** How server sessions and JSON Web Tokens work and how to choose between them.

- Server-side sessions with a session store and cookies
- JWT structure: header, payload, signature
- Stateful vs. stateless auth and scaling implications
- Token expiry, refresh tokens, and rotation
- Storage trade-offs: cookies vs. local storage and CSRF/XSS exposure
- Revocation: easy with sessions, harder with JWTs

**Hands-on:** Implement both a session flow and a JWT flow and note the practical differences you encounter.
**You can move on when:** You can defend a session-vs-JWT choice for a given application.

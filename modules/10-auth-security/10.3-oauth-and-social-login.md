# 10.3 OAuth & Social Login

> Module 10 — Authentication & Security · Phase 3

**What you'll learn:** How delegated authorization works and how to add third-party sign-in.

- OAuth 2.0 roles: client, resource owner, authorization server
- The authorization-code flow step by step
- Scopes, access tokens, and refresh tokens
- OpenID Connect and the ID token for authentication
- Handling the callback and provisioning a local user
- Security pitfalls: state parameter, redirect URI validation, PKCE

**Hands-on:** Add "Sign in with GitHub or Google" using the authorization-code flow and create or link a local account.
**You can move on when:** A user can log in via a third-party provider and you store a corresponding local identity.

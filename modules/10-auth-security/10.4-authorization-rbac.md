# 10.4 Authorization (RBAC)

> Module 10 — Authentication & Security · Phase 3

**What you'll learn:** How to control what authenticated users are allowed to do using roles.

- Roles, permissions, and the principle of least privilege
- Role-based access control (RBAC) vs. attribute-based (ABAC)
- Enforcing authorization in middleware vs. in services
- Resource ownership checks (can this user edit this post?)
- Returning 401 vs. 403 correctly
- Avoiding insecure direct object references

**Hands-on:** Add reusable authorization middleware that restricts routes by role and ownership.
**You can move on when:** Admin-only and owner-only routes correctly reject unauthorized users with 403.

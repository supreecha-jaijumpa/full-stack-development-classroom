# 17.3 Debugging in Production

> Module 17 — Senior Engineering Practices · Phase 5

**What you'll learn:** How to find and fix issues in a live system using observability rather than guesswork.

- The three pillars: logs, metrics, and distributed traces
- Structured logging and correlation IDs to follow a request
- Forming and testing a hypothesis instead of randomly changing things
- Reproducing safely: feature flags, staging, and read-only inspection
- Reading dashboards and alerts to localize the failure
- Mitigate first, then root-cause: rollback, feature flag off, scale up

**Hands-on:** Given logs/metrics for a failing service, write up your diagnosis: hypothesis, evidence, root cause, and the fix.
**You can move on when:** You can take a production symptom and trace it to a root cause using evidence rather than speculation.

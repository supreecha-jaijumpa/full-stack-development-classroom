# 3.4 DOM Manipulation

> Module 03 — JavaScript Fundamentals · Phase 1

**What you'll learn:** How to read and change the page from JavaScript.

- The DOM as a tree of nodes representing the page
- Selecting elements with `querySelector` and `querySelectorAll`
- Reading and changing text, attributes, and classes
- Creating, appending, and removing elements
- Updating styles and toggling classes
- Why minimizing DOM updates matters for performance

**Hands-on:** Build a to-do list that adds list items to the DOM and removes them on click.
**You can move on when:** You can render a list from a JS array into the page and update it without reloading.

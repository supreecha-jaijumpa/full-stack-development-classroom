# 3.8 Build an Interactive App (hands-on)

> Module 03 — JavaScript Fundamentals · Phase 1

**What you'll learn:** How to combine every JavaScript fundamental into a complete, deployed app.

- Planning the app: data source, UI, and interactions
- Fetching data from a public API with `async`/`await`
- Rendering the data to the DOM from JavaScript
- Adding filtering or search via events and array methods
- Organizing the code into ES modules
- Deploying the app and writing a clear README

**Hands-on:** Build and deploy a vanilla-JS app that fetches API data, renders it, and lets users filter it.
**You can move on when:** Your live app loads real data, filters on interaction, and ships with a README.

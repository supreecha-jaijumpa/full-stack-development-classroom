# 3.3 Arrays & Objects

> Module 03 — JavaScript Fundamentals · Phase 1

**What you'll learn:** How to model and transform collections and structured data.

- Creating and accessing arrays and objects
- Mutating vs non-mutating array methods
- Higher-order methods: `map`, `filter`, `reduce`, `find`, `some`, `every`
- Object properties, methods, and shorthand syntax
- Destructuring and the spread/rest operators
- Iterating with `for...of`, `Object.keys`, and `Object.entries`

**Hands-on:** Take an array of user objects and produce a filtered, sorted summary with `map`/`filter`/`reduce`.
**You can move on when:** You can transform a dataset without mutating the original array.

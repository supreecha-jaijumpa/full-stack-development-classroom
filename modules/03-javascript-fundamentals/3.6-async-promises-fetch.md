# 3.6 Async, Promises & fetch

> Module 03 — JavaScript Fundamentals · Phase 1

**What you'll learn:** How JavaScript handles work that takes time, like network requests.

- Synchronous vs asynchronous code and the event loop (high level)
- Callbacks and the problems they cause
- Promises: `then`, `catch`, `finally`, and chaining
- `async`/`await` for readable asynchronous code
- Using `fetch` to request JSON from an API
- Handling errors, loading states, and failed responses

**Hands-on:** Fetch data from a public API with `async`/`await` and log it, handling the error case.
**You can move on when:** You can fetch and display remote data while gracefully handling failures.

# 3.1 Variables, Types & Operators

> Module 03 — JavaScript Fundamentals · Phase 1

**What you'll learn:** How JavaScript stores values and how operators combine them.

- Declaring variables with `let` and `const` (and why to avoid `var`)
- Primitive types: string, number, boolean, `null`, `undefined`, symbol, bigint
- Type coercion and the difference between `==` and `===`
- Arithmetic, comparison, logical, and assignment operators
- Template literals and basic string handling
- Truthy/falsy values and short-circuit evaluation

**Hands-on:** Write a script logging the outcome of several `==` vs `===` comparisons, predicting each first.
**You can move on when:** You can predict the type and value of an expression involving coercion.

# 3.2 Functions & Scope

> Module 03 — JavaScript Fundamentals · Phase 1

**What you'll learn:** How to write reusable functions and reason about where variables live.

- Function declarations, expressions, and arrow functions
- Parameters, default values, and the `arguments`/rest pattern
- Return values and pure vs side-effecting functions
- Scope: global, function, and block scope
- Closures and why inner functions remember outer variables
- A first look at `this` and how call context affects it

**Hands-on:** Build a `makeCounter()` factory using a closure and call it twice independently.
**You can move on when:** You can explain why a closure keeps its variable alive after the outer function returns.

# 3.7 ES Modules

> Module 03 — JavaScript Fundamentals · Phase 1

**What you'll learn:** How to split JavaScript across files and share code with imports and exports.

- Why modules exist: encapsulation and reuse
- Named exports vs the default export
- Importing with `import` and module paths
- How `<script type="module">` works in the browser
- Module scope and that each module runs once
- A first look at how bundlers (like Vite) use modules

**Hands-on:** Refactor a single script into `data.js`, `ui.js`, and `main.js` with explicit imports/exports.
**You can move on when:** Your app runs split across multiple modules with no global leakage.

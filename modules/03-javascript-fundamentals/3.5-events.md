# 3.5 Events

> Module 03 — JavaScript Fundamentals · Phase 1

**What you'll learn:** How to make pages interactive by responding to user input.

- Registering listeners with `addEventListener`
- The event object and useful properties like `target` and `key`
- Common events: click, input, submit, keydown, and more
- Event bubbling, capturing, and `stopPropagation`
- Preventing default behavior with `preventDefault`
- Event delegation for efficiently handling many elements

**Hands-on:** Add one delegated `click` listener on a list container that handles every item.
**You can move on when:** You can handle a form submit without a page reload and read the input values.

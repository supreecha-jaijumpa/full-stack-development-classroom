# 13.5 Server-Side Rendering

> Module 13 — Full-Stack Integration · Phase 4

**What you'll learn:** How rendering on the server changes performance, SEO, and the user's first paint.

- SSR, SSG, ISR, and client-side rendering — what each means and trades off
- Hydration: what happens after server HTML reaches the browser
- Choosing a rendering strategy per route based on data freshness
- SEO and first-contentful-paint benefits of server rendering
- Avoiding hydration mismatches and server-only code leaks

**Hands-on:** Convert one page to server-side rendering and observe the HTML payload vs. client-only.
**You can move on when:** You can explain why a given page should be SSR, SSG, or client-rendered.

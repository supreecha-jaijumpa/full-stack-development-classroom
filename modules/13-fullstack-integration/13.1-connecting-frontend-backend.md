# 13.1 Connecting Frontend & Backend

> Module 13 — Full-Stack Integration · Phase 4

**What you'll learn:** How to make your React frontend talk to your Express backend reliably across the network boundary.

- Calling APIs from React with `fetch`/`axios` and a typed request wrapper
- Configuring CORS, base URLs, and credentials between client and server
- Handling loading, success, and error states in the UI
- Proxying API requests in development to avoid cross-origin friction
- Centralizing API logic instead of scattering raw fetches across components

**Hands-on:** Build a typed API client and render live backend data in a React component.
**You can move on when:** Your frontend can read and write data through the backend with visible loading and error states.

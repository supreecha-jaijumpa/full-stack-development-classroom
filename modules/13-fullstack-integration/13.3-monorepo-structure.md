# 13.3 Monorepo Structure

> Module 13 — Full-Stack Integration · Phase 4

**What you'll learn:** How to keep frontend, backend, and shared code in one repository without dependency chaos.

- Workspaces with npm/pnpm/yarn and a `packages/` or `apps/` layout
- Sharing code via a local `shared` package
- Managing scripts, builds, and dependencies across workspaces
- Optional tooling: Turborepo or Nx for caching and task orchestration
- Keeping boundaries clean so packages stay independently buildable

**Hands-on:** Restructure your app into workspaces for `web`, `api`, and `shared`.
**You can move on when:** You can install once at the root and build all workspaces from a single command.

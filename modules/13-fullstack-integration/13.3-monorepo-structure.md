# 13.3 Monorepo Structure

> Module 13 — Full-Stack Integration · Phase 4

**What you'll learn:** How to keep a TypeScript frontend, a Go backend, and their contract in one repository without dependency chaos.

- An `apps/web`, `apps/api`, and `contracts` layout
- pnpm workspaces for TypeScript and a Go module for the API
- Sharing the OpenAPI contract instead of sharing code
- A root `Makefile` for generate, build, and test across languages
- Keeping boundaries clean so each app stays independently buildable

**Hands-on:** Restructure your app into `apps/web`, `apps/api`, and `contracts`.
**You can move on when:** You can generate, build, and test both apps from a single root command.

# 13.4 Next.js Full-Stack

> Module 13 — Full-Stack Integration · Phase 4

**What you'll learn:** How to build frontend and backend together in a single Next.js project.

- App Router structure, layouts, and file-based routing
- API routes / route handlers for backend logic
- Server Components vs. Client Components and when to use each
- Data fetching on the server and passing it to the UI
- Reading the database directly from server code via Prisma

**Hands-on:** Build a Next.js page backed by a route handler that reads from the database.
**You can move on when:** A Next.js page renders real DB data fetched on the server.

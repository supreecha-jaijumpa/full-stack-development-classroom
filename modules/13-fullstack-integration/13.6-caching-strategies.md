# 13.6 Caching Strategies

> Module 13 — Full-Stack Integration · Phase 4

**What you'll learn:** Where to cache in a full-stack app and how to keep cached data correct.

- HTTP caching with `Cache-Control`, `ETag`, and revalidation
- Client-side caching with React Query / SWR (stale-while-revalidate)
- Server-side and in-memory caching for hot read paths
- Cache invalidation strategies and TTLs
- Recognizing what is safe to cache vs. what must stay fresh

**Hands-on:** Add an HTTP cache header plus an in-memory cache to a read-heavy endpoint.
**You can move on when:** A repeated request is served from cache and invalidates correctly on write.

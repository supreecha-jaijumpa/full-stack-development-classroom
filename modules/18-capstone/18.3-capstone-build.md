# 18.3 Capstone Build

> Module 18 — Capstone · Phase 5

**What you'll learn:** How to build your capstone MVP end to end with the quality bar of a real product.

- Implementing authenticated users and protected routes
- Building the backend API and data layer with Prisma/PostgreSQL
- Building a typed React/Next.js frontend against your API
- Writing meaningful tests for frontend and backend
- Working in small commits and short-lived branches
- Keeping the app deployable at every step

**Hands-on:** Build the MVP — authenticated users, real database, tested frontend and backend, working end to end.
**You can move on when:** A user can sign in and complete the core flow, with tests passing on both sides.

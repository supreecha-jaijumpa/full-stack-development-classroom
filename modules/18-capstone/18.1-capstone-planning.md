# 18.1 Capstone Planning & Scoping

> Module 18 — Capstone · Phase 5

**What you'll learn:** How to scope a capstone that is ambitious enough to prove seniority yet small enough to actually finish.

- Choosing a problem worth solving with real users in mind
- Defining the MVP and writing down explicit non-goals
- Slicing features into thin, shippable vertical increments
- Setting a realistic timeline with buffer for the unknown
- Identifying the riskiest assumptions to validate first
- Avoiding scope creep once the build starts

**Hands-on:** Write a one-page project brief: problem, target users, MVP feature list, explicit non-goals, and a rough timeline.
**You can move on when:** Your brief defines an MVP you could build in the time available, with non-goals written down.

# Module 18: Capstone

> Status: 🔒 Locked (complete the previous module first)
> Estimated Time: 4–6 weeks
> Phase: Phase 5 — Senior Level
> Fast Track: See the entry point table in `plan/roadmap.md`.

---

## Learning Objectives
- [ ] Scope a realistic, achievable product and define its MVP boundaries
- [ ] Produce an architecture and design doc that justifies your technical choices
- [ ] Build a production-grade full-stack app with authenticated users and a real database
- [ ] Test both frontend and backend, and ship through CI/CD
- [ ] Deploy, monitor, and harden the application for production
- [ ] Present and defend your work as in a senior engineering interview

## Exercises
*(Unlocks as each topic is covered)*
- [ ] Exercise 18.1: Write a one-page project brief: problem, target users, MVP feature list, explicit non-goals, and a rough timeline.
- [ ] Exercise 18.2: Write the capstone design doc: architecture diagram, data model, tech-stack justification, and key trade-offs.
- [ ] Exercise 18.3: Build the MVP — authenticated users, real database, tested frontend and backend, working end to end.
- [ ] Exercise 18.4: Deploy via CI/CD with monitoring and logging in place, and complete a security/hardening pass.
- [ ] Exercise 18.5: Present the project as a senior interview defense, covering architecture, trade-offs, and what you'd do at 100x scale.

---

## Module Assessment
- Pass when: all exercises done + the deployed app, design doc, and live presentation reviewed by mentor
- Milestone: Design, build, test, deploy, and present a production-grade full-stack application of your own choosing. It must include: authenticated users, a real database, a tested frontend and backend, CI/CD, monitoring, and a written design doc. Present it as if defending it in a senior engineering interview — architecture, trade-offs, what you'd do differently at 100x scale.
- Unlocks: Graduation — you're a senior-capable full-stack engineer.

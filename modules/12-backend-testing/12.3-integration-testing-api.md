# 12.3 Integration Testing the API

> Module 12 — Backend Testing · Phase 3

**What you'll learn:** How to test real HTTP behavior through your routing, middleware, and handlers.

- What an integration test covers vs. a unit test
- Driving the Express app with Supertest
- Asserting status codes, headers, and response bodies
- Testing auth-protected and validation-failing routes
- Setting up and tearing down state per test
- Keeping integration tests reliable and order-independent

**Hands-on:** Integration-test a full request/response cycle through your routes with Supertest.
**You can move on when:** A test sends a real HTTP request and asserts the status and body end to end.

# 12.2 Unit Testing Services

> Module 12 — Backend Testing · Phase 3

**What you'll learn:** How to test business logic in isolation, fast and deterministically, with Vitest.

- Structuring tests with Vitest (`describe`, `it`, `expect`)
- Testing pure functions and service-layer logic
- Covering edge cases, boundaries, and error paths
- Test doubles: stubs, spies, and mocks
- Isolating units from the database and network
- Keeping tests fast, focused, and independent

**Hands-on:** Unit-test a service or business rule, including its edge cases, with dependencies mocked.
**You can move on when:** Your service tests run in milliseconds and pass without a database or network.

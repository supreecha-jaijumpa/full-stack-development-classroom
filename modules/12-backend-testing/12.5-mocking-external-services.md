# 12.5 Mocking External Services

> Module 12 — Backend Testing · Phase 3

**What you'll learn:** How to keep tests deterministic and offline when your code calls third parties.

- Why external calls make tests slow and flaky
- Mocking HTTP at the boundary (e.g. nock / MSW)
- Stubbing SDK clients and module dependencies
- Simulating success, failure, timeout, and rate-limit responses
- Verifying requests sent to external services
- Contract tests vs. mocks: keeping mocks honest

**Hands-on:** Replace a third-party call with a mock and assert behavior on both success and failure.
**You can move on when:** Your tests pass with no network access and cover the external failure cases.

# 12.4 Test Databases & Fixtures

> Module 12 — Backend Testing · Phase 3

**What you'll learn:** How to test against a real database without flakiness or leftover state.

- Why a real test database beats fully mocking the data layer
- Spinning up a disposable database (Docker / Testcontainers)
- Applying migrations to the test database
- Fixtures and factories for repeatable seed data
- Isolation strategies: transactions, truncation, per-test reset
- Keeping the test database separate from dev and prod

**Hands-on:** Stand up a disposable test database with seeded fixtures and reliable per-test cleanup.
**You can move on when:** Your integration suite runs repeatably against a real database with no cross-test contamination.

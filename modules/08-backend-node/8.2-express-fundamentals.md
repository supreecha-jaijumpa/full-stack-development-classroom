# 8.2 Express Fundamentals

> Module 08 — Backend with Node.js · Phase 3

**What you'll learn:** How to structure an Express application with routes, handlers, and the request/response lifecycle in TypeScript.

- Creating an app, mounting routers, and the `req`/`res`/`next` signature
- Route parameters, query strings, and request bodies
- Sending JSON, status codes, and headers correctly
- Organizing routes into modular router files
- Typing handlers and request payloads with TypeScript
- Serving static assets and the basics of CORS

**Hands-on:** Scaffold a TypeScript Express server with a `/health` endpoint and at least one modular router.
**You can move on when:** Your server responds to a GET and a POST route with correctly typed JSON.

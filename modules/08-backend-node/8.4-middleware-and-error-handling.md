# 8.4 Middleware & Error Handling

> Module 08 — Backend with Node.js · Phase 3

**What you'll learn:** How to compose request-processing middleware and funnel all failures through one reliable handler.

- The middleware chain and the order of execution
- Application-level, router-level, and built-in middleware
- Writing logging, authentication, and 404 middleware
- The four-argument error-handling middleware signature
- Custom typed error classes and mapping them to status codes
- Catching async errors so rejections don't crash the process

**Hands-on:** Add a request logger, a 404 handler, and a centralized error handler with at least one custom error class.
**You can move on when:** A thrown error in any route returns a consistent JSON error with the right status.

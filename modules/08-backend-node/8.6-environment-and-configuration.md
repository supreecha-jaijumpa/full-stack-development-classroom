# 8.6 Environment & Configuration

> Module 08 — Backend with Node.js · Phase 3

**What you'll learn:** How to manage configuration and secrets safely across development, test, and production.

- Environment variables and the `.env` file pattern
- Loading and parsing config (e.g. dotenv) at startup
- Validating config and failing fast on missing required values
- Building a typed, centralized config object
- Keeping secrets out of source control (`.gitignore`, examples)
- Per-environment overrides for dev, test, and prod

**Hands-on:** Build a typed config module that loads `.env`, validates required variables, and throws on startup if any are missing.
**You can move on when:** Your app refuses to start with a clear message when a required variable is absent.

# 8.5 Request Validation

> Module 08 — Backend with Node.js · Phase 3

**What you'll learn:** How to validate and sanitize incoming data before it reaches your business logic.

- Why never to trust client input (security and data integrity)
- Schema-based validation with a library like Zod
- Validating bodies, query parameters, and route params
- Coercion, defaults, and transforming input into typed values
- Returning structured 422 validation errors
- Reusable validation middleware

**Hands-on:** Write a validation middleware that checks a request against a schema and returns 422 with field-level details.
**You can move on when:** Invalid input is rejected with a clear, structured error and valid input is fully typed downstream.

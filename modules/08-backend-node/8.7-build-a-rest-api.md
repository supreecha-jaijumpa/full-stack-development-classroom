# 8.7 Build a REST API (hands-on)

> Module 08 — Backend with Node.js · Phase 3

**What you'll learn:** How to assemble routing, validation, error handling, and configuration into one cohesive, documented API.

- Project structure: routes, controllers, services, and config
- Wiring validation and centralized error handling end to end
- Implementing full CRUD for a real domain resource
- Consistent response and error envelopes
- Documenting endpoints (a README or simple API reference)
- Manual testing with a REST client before automated tests

**Hands-on:** Ship a typed Express REST API for a real domain with routing, validation, error handling, env config, and endpoint docs.
**You can move on when:** A reviewer can run your API from a clean clone using only the documented setup steps.

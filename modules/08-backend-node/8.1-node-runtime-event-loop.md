# 8.1 Node Runtime & the Event Loop

> Module 08 — Backend with Node.js · Phase 3

**What you'll learn:** How Node.js executes JavaScript on a single thread while handling I/O concurrently through the event loop.

- The V8 engine, libuv, and what "non-blocking I/O" actually means
- Event loop phases: timers, pending callbacks, poll, check, close
- `process.nextTick` and microtasks vs. macrotasks (Promises vs. timers)
- The call stack, the callback queue, and why blocking the loop hurts everyone
- Worker threads and the thread pool for CPU-bound work
- Common pitfalls: synchronous file reads, tight loops, unhandled rejections

**Hands-on:** Predict and then verify the log order of mixed `setTimeout`, `setImmediate`, `nextTick`, and Promise callbacks.
**You can move on when:** You can correctly order the output of a mixed async script and explain why.

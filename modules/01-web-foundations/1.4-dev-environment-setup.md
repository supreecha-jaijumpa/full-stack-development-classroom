# 1.4 Dev Environment Setup

> Module 01 — Web Foundations & Dev Setup · Phase 1

**What you'll learn:** How to install and configure the core tools you'll use for the rest of the course.

- Installing a code editor (VS Code) and useful extensions (ESLint, Prettier)
- Installing Node.js via an LTS release or a version manager (nvm/fnm)
- Verifying installs with `node --version` and `npm --version`
- Understanding what `npm`/`npx` are and the role of `package.json`
- Setting up a sane editor config: formatting on save and consistent indentation
- Organizing a projects folder so repos are easy to find

**Hands-on:** Install VS Code and Node, then run `node -v && npm -v` in the terminal.
**You can move on when:** You can open a new folder in your editor and run a Node script without errors.

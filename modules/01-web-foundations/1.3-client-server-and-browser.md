# 1.3 Client, Server & the Browser

> Module 01 — Web Foundations & Dev Setup · Phase 1

**What you'll learn:** The division of responsibilities between the client, the server, and the browser runtime.

- What "client-side" vs "server-side" actually means in practice
- The browser as a runtime: rendering engine, JavaScript engine, and Web APIs
- What a server does: receive requests, run logic, talk to data, return responses
- Static vs dynamic content and how each is served
- Where state can live: in the browser, in the server, in a database
- A first look at how front end and back end talk over HTTP/JSON

**Hands-on:** Open DevTools → Console and run `navigator.userAgent` to inspect your browser client.
**You can move on when:** You can correctly place a given feature (e.g. validation, auth, rendering) on client, server, or both.

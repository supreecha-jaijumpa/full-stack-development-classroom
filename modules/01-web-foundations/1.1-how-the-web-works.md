# 1.1 How the Web Works

> Module 01 — Web Foundations & Dev Setup · Phase 1

**What you'll learn:** The end-to-end journey of a web request, from typing a URL to seeing a rendered page.

- What a URL is made of: scheme, host, port, path, and query string
- How DNS resolves a domain name into an IP address
- The TCP connection and (for HTTPS) the TLS handshake that secures it
- The request/response round trip between browser and server
- How the browser parses HTML, CSS, and JS to paint the page
- Where latency comes from and why caching and CDNs help

**Hands-on:** Open DevTools → Network, reload `https://example.com`, and watch the request waterfall.
**You can move on when:** You can verbally walk a peer through all the steps between pressing Enter on a URL and seeing pixels.

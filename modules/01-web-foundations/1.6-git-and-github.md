# 1.6 Git & GitHub

> Module 01 — Web Foundations & Dev Setup · Phase 1

**What you'll learn:** How to track changes with Git and collaborate through GitHub.

- The core mental model: working tree, staging area, and commit history
- Everyday commands: `git init`, `git add`, `git commit`, `git status`, `git log`
- Branching and merging, and why feature branches matter
- Connecting a local repo to a remote with `git remote` and `git push`
- Cloning, pulling, and resolving a basic merge conflict
- Writing clear commit messages and using `.gitignore`

**Hands-on:** Initialize a repo, commit `hello.html`, create a GitHub repo, and `git push` to it.
**You can move on when:** Your `hello world` page is visible in a GitHub repo with a clean commit history.

# 1.2 HTTP Fundamentals

> Module 01 — Web Foundations & Dev Setup · Phase 1

**What you'll learn:** How HTTP structures the messages clients and servers exchange.

- The shape of a request: method, path, headers, and body
- The shape of a response: status line, headers, and body
- Common methods (GET, POST, PUT, PATCH, DELETE) and when to use each
- Status code families: 2xx success, 3xx redirect, 4xx client error, 5xx server error
- Important headers: `Content-Type`, `Authorization`, `Cache-Control`, cookies
- The idea of statelessness and how cookies/tokens add session context

**Hands-on:** Use `curl -i https://example.com` and read every line of the response.
**You can move on when:** Given a status code and headers, you can explain what the server is telling the client.

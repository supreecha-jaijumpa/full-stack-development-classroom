# Module 01: Web Foundations & Dev Setup

> Status: 🔓 Unlocked — start here
> Estimated Time: 1–2 weeks
> Phase: Phase 1 — Foundations
> Fast Track: See the entry point table in `plan/roadmap.md`.

---

## Learning Objectives
- [ ] Explain what happens between typing a URL and seeing a rendered page
- [ ] Describe the roles of client, server, browser, and DNS in the request flow
- [ ] Read and reason about HTTP requests, responses, methods, and status codes
- [ ] Install and configure a working dev environment (editor, runtime, terminal)
- [ ] Navigate the file system and run programs confidently from the command line
- [ ] Use Git for version control and push a repository to GitHub
- [ ] Publish a simple "hello world" HTML page and share its source on GitHub

## Exercises
*(Unlocks as each topic is covered)*
- [ ] Exercise 1.1: Diagram the journey of a request from your browser to `example.com` and back, labeling DNS, TCP, and HTTP steps.
- [ ] Exercise 1.2: Use your browser's DevTools Network tab to inspect a real page load and list three response headers and their meaning.
- [ ] Exercise 1.3: Write a one-page note distinguishing what runs on the client vs. the server for a typical web app.
- [ ] Exercise 1.4: Install VS Code and Node.js, then run `node --version` and `npm --version` and screenshot the output.
- [ ] Exercise 1.5: Using only the terminal, create a project folder, add a file, list contents, and remove the file.
- [ ] Exercise 1.6: Create a GitHub repo, commit a `hello.html` page, and push it to `main`.

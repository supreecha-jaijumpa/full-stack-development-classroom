# 1.5 Command Line Basics

> Module 01 — Web Foundations & Dev Setup · Phase 1

**What you'll learn:** How to navigate, create, and run things from a terminal with confidence.

- Navigating the file system: `pwd`, `cd`, `ls`/`dir`
- Creating and removing files and folders: `mkdir`, `touch`, `rm`, `mv`, `cp`
- Reading and searching file contents from the shell
- Running programs and scripts, and reading their output and exit status
- Using flags, arguments, and piping output between commands
- Tips for your shell: history, tab completion, and clearing the screen

**Hands-on:** From the terminal, create a `practice` folder, add a file, list it, then delete it — no GUI.
**You can move on when:** You can complete a small file-management task entirely from the command line.

# 4.4 npm & Package Management

> Module 04 — Modern JavaScript & TypeScript · Phase 2

**What you'll learn:** How to install, version, and script the third-party packages that every modern frontend depends on.

- `package.json` anatomy: `dependencies`, `devDependencies`, `scripts`, and metadata.
- Installing packages and the role of `node_modules` and the lockfile (`package-lock.json`).
- Semantic versioning and the meaning of `^`, `~`, and exact version pins.
- npm scripts: defining and chaining tasks, running with `npm run`.
- `npx` for running package binaries without a global install.
- Auditing and updating dependencies; understanding security advisories.

**Hands-on:** Initialize a project with `npm init -y`, add a dependency and a dev dependency, and create `dev`/`build`/`lint` scripts.
**You can move on when:** You can explain why the lockfile should be committed and predict what `^1.2.3` will and won't upgrade to.

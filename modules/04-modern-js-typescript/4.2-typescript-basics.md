# 4.2 TypeScript Basics

> Module 04 — Modern JavaScript & TypeScript · Phase 2

**What you'll learn:** How to add static types to JavaScript and why catching errors at compile time saves you at runtime.

- Primitive type annotations: `string`, `number`, `boolean`, `null`, `undefined`.
- Typing functions: parameter types, return types, and optional/default parameters.
- Object types and `interface` vs. `type` aliases for shaping data.
- Arrays, tuples, and the `readonly` modifier.
- Type inference — when to annotate explicitly and when to let TypeScript figure it out.
- The compiler: `tsc`, `tsconfig.json`, and what `strict` mode turns on.

**Hands-on:** Run `tsc --init`, enable `strict`, and add types to a small JS utility module until it compiles cleanly.
**You can move on when:** You can type a function's parameters and return value and explain one bug the type checker caught for you.

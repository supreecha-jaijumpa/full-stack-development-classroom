# 4.3 TypeScript Types Deep Dive

> Module 04 — Modern JavaScript & TypeScript · Phase 2

**What you'll learn:** The advanced type-system features that let you model real-world data precisely without reaching for `any`.

- Union and intersection types, plus literal types for finite sets of values.
- Type narrowing with `typeof`, `in`, discriminated unions, and type guards.
- Generics for reusable, type-safe functions and containers like `Result<T>`.
- Utility types: `Partial`, `Pick`, `Omit`, `Record`, `ReturnType`.
- `unknown` vs. `any` and why `unknown` forces safe handling.
- Typing async data and modeling loading/error/success states as a union.

**Hands-on:** Model a shopping-cart domain with discriminated unions and a generic `Result<T>` wrapper, then write a type guard that narrows it.
**You can move on when:** You can replace an `any` in existing code with a precise union or generic type and explain why it is safer.

# 4.6 Linting & Formatting (ESLint, Prettier)

> Module 04 — Modern JavaScript & TypeScript · Phase 2

**What you'll learn:** How to enforce consistent style and catch bugs automatically with ESLint and Prettier.

- The difference between linting (correctness) and formatting (style).
- Configuring ESLint with the TypeScript parser and recommended rule sets.
- Prettier setup and avoiding conflicts with ESLint (`eslint-config-prettier`).
- Adding `lint` and `format` npm scripts and auto-fixing with `--fix`.
- Editor integration: format-on-save and inline lint warnings.
- Running checks in CI / pre-commit so bad code never lands.

**Hands-on:** Add ESLint + Prettier to a Vite TS project so that `npm run lint` and `npm run format` both pass with zero warnings.
**You can move on when:** Your project lints and formats cleanly via npm scripts, and you can explain which tool owns a given rule.

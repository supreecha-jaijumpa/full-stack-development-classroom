# 4.1 Modern JavaScript (ES2015+)

> Module 04 — Modern JavaScript & TypeScript · Phase 2

**What you'll learn:** The modern JavaScript language features that React and TypeScript assume you already use fluently.

- `let`/`const` and block scoping — why `var` is avoided and how the temporal dead zone works.
- Arrow functions and lexical `this`, plus implicit returns for concise callbacks.
- Destructuring and spread/rest for objects and arrays, including default values.
- ES modules: `import`/`export`, named vs. default exports, and tree-shaking implications.
- Promises and `async`/`await` for asynchronous code, with `try`/`catch` error handling.
- Template literals, optional chaining (`?.`), and nullish coalescing (`??`).

**Hands-on:** Take a small callback-style script and rewrite it using modules, destructuring, and `async`/`await`, running it with `node script.mjs`.
**You can move on when:** You can fetch and transform JSON from an API using `async`/`await` and destructure the result without looking anything up.

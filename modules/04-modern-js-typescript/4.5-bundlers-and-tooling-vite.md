# 4.5 Bundlers & Tooling (Vite)

> Module 04 — Modern JavaScript & TypeScript · Phase 2

**What you'll learn:** What a bundler does and how Vite gives you a fast dev server and an optimized production build.

- Why browsers need bundling: modules, transpilation, and asset handling.
- Vite's dev server: native ES modules and hot module replacement (HMR).
- Scaffolding a project with `npm create vite@latest` and the React + TS template.
- `vite.config.ts`: plugins, path aliases, and the `@/` import convention.
- Environment variables with `import.meta.env` and `.env` files.
- The production build (`vite build`) and previewing it (`vite preview`).

**Hands-on:** Scaffold a Vite + React + TypeScript app, add a `@/` path alias, read an env variable, and run both `dev` and `build`.
**You can move on when:** You can scaffold a Vite TS project from scratch and explain the difference between dev mode and a production build.

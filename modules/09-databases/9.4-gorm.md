# 9.4 GORM

> Module 09 — Databases · Phase 3

**What you'll learn:** How to model and query a PostgreSQL database in Go with GORM, and when to drop down to raw SQL.

- Models, struct tags, and relations (`belongsTo`, `hasMany`, `many2many`)
- Connecting with the Postgres driver, and passing a request's `context` with `WithContext`
- CRUD: `Create`, `Find`, `First`, `Updates`, `Delete`, and how soft delete behaves
- Loading relations with `Preload` and `Joins`
- Filtering, ordering, and pagination, plus the zero-value trap in `Updates` with a struct
- The cost of N+1 queries, reading the generated SQL, and using `Raw` when SQL is clearer

**Hands-on:** Define your blog schema as GORM models and run CRUD and relation queries behind the repository interface from your Module 08 API.
**You can move on when:** You can fetch a post with its author, comments, and tags, and show the SQL GORM generated for it.

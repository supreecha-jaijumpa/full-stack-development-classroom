# 9.7 Indexes & Query Performance

> Module 09 — Databases · Phase 3

**What you'll learn:** How to find slow queries and use indexes to make them fast.

- How indexes work (B-tree basics) and the read/write trade-off
- Reading query plans with EXPLAIN and EXPLAIN ANALYZE
- Single-column, composite, and unique indexes
- Indexing foreign keys and frequently filtered columns
- When indexes are ignored or hurt performance
- Measuring before and after to prove an index helps

**Hands-on:** Profile a slow query, add a well-chosen index, and compare the query plans.
**You can move on when:** You can use EXPLAIN to justify adding an index and show the measured speedup.

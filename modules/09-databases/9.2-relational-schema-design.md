# 9.2 Relational Schema Design

> Module 09 — Databases · Phase 3

**What you'll learn:** How to model a real domain as tables with sound keys and relationships.

- Tables, columns, and choosing appropriate data types
- Primary keys, surrogate vs. natural keys
- Foreign keys and referential integrity
- One-to-one, one-to-many, and many-to-many relationships
- Join tables for many-to-many associations
- Constraints: NOT NULL, UNIQUE, CHECK, and defaults

**Hands-on:** Draw and write the DDL for a blog domain with users, posts, comments, and tags.
**You can move on when:** Your schema enforces every relationship with the correct keys and constraints.

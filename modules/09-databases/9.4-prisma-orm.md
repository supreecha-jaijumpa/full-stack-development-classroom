# 9.4 Prisma ORM

> Module 09 — Databases · Phase 3

**What you'll learn:** How to model and query a PostgreSQL database in TypeScript with Prisma.

- The Prisma schema: models, fields, and relations
- Generating and using the type-safe Prisma Client
- CRUD operations: create, findMany, update, delete
- Relation queries, includes, and selects
- Filtering, ordering, and pagination with Prisma
- The cost of N+1 queries and how to avoid them

**Hands-on:** Define your blog schema in Prisma and run typed CRUD and relation queries against it.
**You can move on when:** You can fetch a post with its author, comments, and tags in a single typed query.

# 9.1 SQL Fundamentals

> Module 09 — Databases · Phase 3

**What you'll learn:** How to retrieve and combine data from a relational database using core SQL.

- SELECT, WHERE, ORDER BY, and LIMIT
- INSERT, UPDATE, and DELETE basics
- INNER, LEFT, and other joins across tables
- Aggregates with GROUP BY and HAVING
- Subqueries and common table expressions (CTEs)
- NULL handling and data types in PostgreSQL

**Hands-on:** Query a sample database to answer real questions using joins, grouping, and aggregates.
**You can move on when:** You can write a multi-table join with aggregation without reference material.

# 8.7 Request Validation

> Module 08 — Backend with Go · Phase 3

**What you'll learn:** How to validate incoming data with Gin before it reaches your business logic.

- Why never to trust client input (security and data integrity)
- `binding` struct tags, powered by `go-playground/validator`
- Binding bodies, query parameters, and path parameters
- `ShouldBind*` vs. `Bind*`, and why you usually want `ShouldBind*`
- Zero values vs. missing fields, and using pointers for optional input
- Turning `validator.ValidationErrors` into structured 422 responses, and writing a custom validator

**Hands-on:** Write a reusable helper that binds a request and returns 422 with field-level details.
**You can move on when:** Invalid input is rejected with a clear, structured error, and valid input reaches your handler as a typed struct.

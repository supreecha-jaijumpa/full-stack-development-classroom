# 8.5 REST API Design

> Module 08 — Backend with Go · Phase 3

**What you'll learn:** How to design clean, predictable RESTful resources and choose the right HTTP semantics.

- Resources, nouns vs. verbs, and consistent URL structure
- HTTP methods (GET, POST, PUT, PATCH, DELETE) and idempotency
- Status codes that match outcomes (2xx, 4xx, 5xx)
- Request/response shapes and consistent error payloads
- Nested resources, filtering, sorting, and basic pagination
- HATEOAS and the Richardson Maturity Model (awareness level)

**Hands-on:** Design and implement full CRUD endpoints in Gin for one resource, using an in-memory store protected by a mutex, with the correct method and status code for each operation.
**You can move on when:** You can map a CRUD feature to RESTful routes and justify every status code.

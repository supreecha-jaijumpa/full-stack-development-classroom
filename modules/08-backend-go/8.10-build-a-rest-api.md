# 8.10 Build a REST API (hands-on)

> Module 08 — Backend with Go · Phase 3

**What you'll learn:** How to assemble routing, validation, error handling, and configuration into one cohesive, documented Go API.

- Project structure: `cmd/api`, `internal/handler`, `internal/service`, `internal/repository`, `internal/config`
- Keeping storage behind a repository interface, ready for GORM in Module 09
- Implementing full CRUD for a real domain resource
- Consistent response and error envelopes
- Documenting endpoints (a README or simple API reference)
- Manual testing with a REST client, plus `gofmt` and `go vet` before review

**Hands-on:** Ship a Gin REST API for a real domain with routing, validation, error handling, env config, and endpoint docs.
**You can move on when:** A reviewer can run your API from a clean clone using only the documented setup steps.

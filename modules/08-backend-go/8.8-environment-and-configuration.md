# 8.8 Environment & Configuration

> Module 08 — Backend with Go · Phase 3

**What you'll learn:** How to manage configuration and secrets safely across development, test, and production.

- Environment variables and the `.env` file pattern
- Loading `.env` in development with `godotenv`
- Parsing into a typed struct with `caarlos0/env`
- Failing fast at startup on missing or invalid values
- Passing config explicitly instead of using package-level globals
- Keeping secrets out of source control, and per-environment settings such as `GIN_MODE`

**Hands-on:** Build a typed config package that loads `.env`, validates required variables, and stops startup if any are missing.
**You can move on when:** Your app refuses to start with a clear message when a required variable is absent.

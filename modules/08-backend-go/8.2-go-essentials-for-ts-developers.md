# 8.2 Go Essentials for TS Developers

> Module 08 — Backend with Go · Phase 3

**What you'll learn:** How to read and write everyday Go by mapping it onto the TypeScript you already know, and where the two languages really differ.

- The toolchain: `go mod`, `go run`, `go build`, `go test`, `gofmt`
- Packages, imports, and exporting names with a capital letter
- Static types, zero values, and structs with JSON tags vs. TS interfaces
- Values vs. pointers: when a function can change the caller's data
- Slices, maps, `range`, and `nil`
- Errors as return values: `if err != nil`, wrapping with `%w`, `errors.Is`/`errors.As`, and why `panic` is not `throw`

**Hands-on:** Write a small CLI that reads a JSON file into structs, filters the records, prints a result, and handles every error without panicking.
**You can move on when:** You can explain value vs. pointer on your own code, and every returned error in it is handled or wrapped.

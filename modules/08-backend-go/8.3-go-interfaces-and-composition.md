# 8.3 Interfaces & Composition

> Module 08 — Backend with Go · Phase 3

**What you'll learn:** How Go achieves design principles like SOLID with small interfaces and composition instead of classes and inheritance.

- Methods on types, and value vs. pointer receivers
- Implicit interfaces: a type satisfies an interface without declaring it
- Small interfaces, defined where they are used ("accept interfaces, return structs")
- Struct embedding vs. inheritance
- SOLID in Go: focused packages, and dependency inversion through constructor injection
- Generics: what they are for, and when a plain interface is better

**Hands-on:** Build a service that depends on a `Notifier` interface, with one real-looking and one fake implementation passed in through a constructor.
**You can move on when:** You can swap the implementation without changing the service, and explain which SOLID principle that demonstrates.

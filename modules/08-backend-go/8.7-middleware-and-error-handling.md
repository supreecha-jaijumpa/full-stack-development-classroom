# 8.7 Middleware & Error Handling

> Module 08 — Backend with Go · Phase 3

**What you'll learn:** How to compose request-processing middleware in Gin and send every failure through one reliable handler.

- The `gin.HandlerFunc` chain, `c.Next()`, `c.Abort()`, and execution order
- Global, group-level, and route-level middleware
- Writing logging and authentication middleware, plus a `NoRoute` 404 handler
- Centralized error handling: `c.Error()` plus one middleware that reads `c.Errors`
- Custom error types, and mapping them to status codes with `errors.As`
- Panic recovery with `gin.Recovery()`, and why it can't catch a panic in a goroutine you started

**Hands-on:** Add a request logger, a 404 handler, and a centralized error middleware with at least one custom error type.
**You can move on when:** An error returned from any route produces a consistent JSON error with the right status.

# 8.4 Gin Fundamentals

> Module 08 — Backend with Go · Phase 3

**What you'll learn:** How to structure a Gin application with routes, handlers, and the request/response lifecycle.

- `gin.Default()` vs. `gin.New()`, the engine, and router groups
- Handlers and `*gin.Context`
- Path parameters, query strings, and binding JSON bodies into structs
- Sending JSON, status codes, and headers correctly
- Organizing routes by feature package
- CORS with `gin-contrib/cors`, and graceful shutdown with `http.Server`

**Hands-on:** Scaffold a Gin server with a `/health` endpoint and at least one feature route group in its own package.
**You can move on when:** Your server responds to a GET and a POST route using typed request and response structs, and shuts down cleanly on Ctrl+C.

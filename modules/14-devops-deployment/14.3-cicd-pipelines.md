# 14.3 CI/CD Pipelines (GitHub Actions)

> Module 14 — DevOps & Deployment · Phase 4

**What you'll learn:** How to automate testing and deployment every time you push code.

- Workflow YAML: triggers, jobs, steps, and runners
- Setting up Go, running `golangci-lint`, and running `go test -race ./...` in CI
- Caching Go modules and build output to speed up runs
- Build artifacts and matrix builds
- Gating merges on green checks and deploying on push

**Hands-on:** Create a GitHub Actions workflow that lints and tests the Go and frontend code on every push.
**You can move on when:** A push triggers an automated pipeline that passes or fails on your tests.

# 14.4 Cloud Deployment

> Module 14 — DevOps & Deployment · Phase 4

**What you'll learn:** How to get your full-stack app running on a real cloud host.

- Choosing a host (e.g. Render, Railway, Fly.io, Vercel) for app and database
- Deploying from a container image or directly from a repo
- Provisioning a managed PostgreSQL database and connecting to it
- Configuring build/start commands and a public domain
- Running database migrations against the production database

**Hands-on:** Deploy your app to a cloud host with a managed PostgreSQL database.
**You can move on when:** Your app is reachable at a public URL and reads/writes the production database.

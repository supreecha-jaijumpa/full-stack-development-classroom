# 14.1 Docker Fundamentals

> Module 14 — DevOps & Deployment · Phase 4

**What you'll learn:** How containers package your app so it runs the same everywhere.

- Images vs. containers vs. registries
- Writing a Dockerfile: base image, layers, `COPY`, `RUN`, `CMD`
- Building, tagging, and running images locally
- Multi-stage builds to keep production images small
- `.dockerignore`, environment variables, and exposing ports

**Hands-on:** Write a Dockerfile for your backend and build/run it as a container.
**You can move on when:** Your app runs in a container with a single `docker run` command.

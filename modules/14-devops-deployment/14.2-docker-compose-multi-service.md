# 14.2 Docker Compose (multi-service)

> Module 14 — DevOps & Deployment · Phase 4

**What you'll learn:** How to run several containers together as one local stack.

- Defining services in `docker-compose.yml`
- Running the app alongside PostgreSQL
- Networks, volumes for data persistence, and service dependencies
- Passing environment variables and `depends_on` / health checks
- Bringing the stack up and down with `docker compose up`/`down`

**Hands-on:** Write a `docker-compose.yml` that runs your app and PostgreSQL together.
**You can move on when:** `docker compose up` starts your app connected to a database in one command.

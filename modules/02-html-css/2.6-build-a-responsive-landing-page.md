# 2.6 Build a Responsive Landing Page (hands-on)

> Module 02 — HTML & CSS · Phase 1

**What you'll learn:** How to combine semantic HTML, CSS, layout, responsiveness, and accessibility into one shipped project.

- Planning sections: hero, features, testimonials, call-to-action, footer
- Structuring the page with semantic landmarks
- Laying out sections with Flexbox and Grid
- Making every section responsive with a mobile-first approach
- Meeting accessibility checks before shipping
- Deploying to GitHub Pages and sharing a live URL

**Hands-on:** Build the full multi-section landing page and deploy it live to GitHub Pages.
**You can move on when:** Your live URL loads a responsive, accessible page that passes a basic Lighthouse audit.

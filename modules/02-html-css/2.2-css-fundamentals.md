# 2.2 CSS Fundamentals

> Module 02 — HTML & CSS · Phase 1

**What you'll learn:** The core rules of how CSS selects elements and how styles are applied.

- Ways to apply CSS: inline, internal, and external stylesheets
- Selectors: type, class, id, attribute, descendant, and combinators
- The box model: content, padding, border, and margin
- The cascade, specificity, and inheritance
- Units (`px`, `em`, `rem`, `%`) and CSS custom properties (variables)
- Colors, typography, and basic transitions

**Hands-on:** Style a profile card with custom properties, varied selectors, and a hover transition.
**You can move on when:** You can predict which rule wins when two selectors target the same element.

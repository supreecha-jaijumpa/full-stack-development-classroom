# 2.1 Semantic HTML

> Module 02 — HTML & CSS · Phase 1

**What you'll learn:** How to structure page content with elements that describe meaning, not just appearance.

- The anatomy of an HTML document: doctype, `head`, `body`, metadata
- Structural elements: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Text semantics: headings hierarchy, lists, `figure`, `blockquote`, emphasis
- Forms and inputs with proper `label` associations
- Why semantics help SEO, accessibility, and maintainability
- When a plain `div`/`span` is actually the right choice

**Hands-on:** Mark up a blog post page using only semantic elements and validate it with the W3C validator.
**You can move on when:** You can build a page outline that reads correctly with headings and landmarks alone.

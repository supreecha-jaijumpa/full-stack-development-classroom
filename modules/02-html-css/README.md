---

## Learning Objectives
- [ ] Structure content with semantic, well-formed HTML
- [ ] Style pages with CSS using the box model, selectors, and the cascade
- [ ] Build layouts confidently with Flexbox and CSS Grid
- [ ] Make pages responsive across mobile, tablet, and desktop
- [ ] Apply accessibility basics so pages work for everyone
- [ ] Combine these skills to build and deploy a complete landing page
- [ ] Read and debug existing HTML/CSS using browser DevTools

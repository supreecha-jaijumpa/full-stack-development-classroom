# 2.5 Accessibility Basics

> Module 02 — HTML & CSS · Phase 1

**What you'll learn:** How to build pages that work for people using assistive technology.

- Why accessibility matters and who it serves
- Semantic HTML as the foundation of an accessible page
- Text alternatives: `alt` text, labels, and accessible names
- Color contrast and not relying on color alone
- Keyboard navigation, focus order, and visible focus styles
- Introducing ARIA roles and when they're (rarely) needed

**Hands-on:** Run Lighthouse / axe on a page, then fix the reported contrast and labeling issues.
**You can move on when:** You can navigate your page using only the keyboard and a screen reader reads it sensibly.

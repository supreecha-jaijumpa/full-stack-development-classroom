# 2.3 Layout — Flexbox & Grid

> Module 02 — HTML & CSS · Phase 1

**What you'll learn:** How to build robust page layouts with Flexbox and CSS Grid.

- Flexbox: main vs cross axis, `justify-content`, `align-items`, `flex` shorthand
- When to reach for Flexbox (one-dimensional content)
- Grid: defining rows and columns with `grid-template` and `fr` units
- Placing items with lines, areas, and `gap`
- When to reach for Grid (two-dimensional layouts)
- Combining Flexbox and Grid in a real page

**Hands-on:** Build a header nav with Flexbox and a card gallery with Grid on one page.
**You can move on when:** You can choose Flexbox or Grid for a given layout and justify the choice.

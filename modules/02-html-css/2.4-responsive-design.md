# 2.4 Responsive Design

> Module 02 — HTML & CSS · Phase 1

**What you'll learn:** How to make a single layout adapt gracefully to any screen size.

- The viewport meta tag and why it matters on mobile
- Mobile-first thinking and progressive enhancement
- Media queries and choosing sensible breakpoints
- Relative units and fluid sizing with `min()`, `max()`, `clamp()`
- Responsive images with `srcset` and `sizes`
- Testing across devices using browser device emulation

**Hands-on:** Convert a fixed desktop layout into a mobile-first responsive page with two breakpoints.
**You can move on when:** Your page reflows cleanly with no horizontal scroll from 320px to 1440px wide.

# 11.3 API Versioning & Pagination

> Module 11 — API Design & Real-Time · Phase 3

**What you'll learn:** How to evolve an API without breaking clients and how to serve large collections.

- Versioning strategies: URL, header, and media-type
- Deprecation policies and communicating breaking changes
- Offset/limit pagination and its limitations
- Cursor (keyset) pagination for stable, large datasets
- Returning pagination metadata and links
- Filtering and sorting alongside pagination

**Hands-on:** Add a versioned endpoint and implement both offset and cursor pagination on a collection.
**You can move on when:** A large collection paginates correctly via cursor without skipping or duplicating rows.

# 11.7 API Documentation (OpenAPI)

> Module 11 — API Design & Real-Time · Phase 3

**What you'll learn:** How to describe an API formally with OpenAPI and generate useful documentation.

- The OpenAPI specification and its structure
- Describing paths, parameters, request/response schemas
- Documenting auth schemes and error responses
- Generating the spec from code vs. writing it by hand
- Serving interactive docs (Swagger UI / Redoc)
- Using the spec for client generation and contract testing

**Hands-on:** Produce an OpenAPI spec for your API and serve interactive documentation from it.
**You can move on when:** Another developer can understand and call your API from the generated docs alone.

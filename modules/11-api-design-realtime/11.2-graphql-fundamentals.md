# 11.2 GraphQL Fundamentals

> Module 11 — API Design & Real-Time · Phase 3

**What you'll learn:** How GraphQL models an API as a typed graph and when it beats REST.

- The schema, types, queries, mutations, and subscriptions
- Resolvers and how a query is executed
- Querying exactly the fields you need (over/under-fetching)
- The N+1 problem and batching with DataLoader
- Errors, nullability, and schema evolution
- Trade-offs vs. REST: flexibility vs. caching and complexity

**Hands-on:** Expose part of your domain via a GraphQL schema with at least one query and one mutation.
**You can move on when:** You can fetch nested data in one GraphQL query and explain a case where GraphQL beats REST.

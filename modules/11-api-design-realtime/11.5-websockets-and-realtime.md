# 11.5 WebSockets & Real-Time

> Module 11 — API Design & Real-Time · Phase 3

**What you'll learn:** How to push live updates to clients using persistent connections.

- HTTP polling vs. SSE vs. WebSockets
- The WebSocket handshake and the persistent connection lifecycle
- Building a server with `ws` or Socket.IO
- Rooms, channels, and broadcasting events
- Authenticating socket connections
- Scaling real-time across multiple instances (pub/sub)

**Hands-on:** Build a real-time feature such as live comments or notifications over WebSockets.
**You can move on when:** Two connected clients see each other's updates in real time without refreshing.

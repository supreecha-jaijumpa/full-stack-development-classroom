# 11.4 File Uploads

> Module 11 — API Design & Real-Time · Phase 3

**What you'll learn:** How to accept, validate, and store uploaded files safely.

- Multipart form data and streaming uploads
- Handling uploads in Express (e.g. multer)
- Validating type, size, and content
- Storage options: local disk vs. object storage (S3)
- Direct-to-storage uploads with presigned URLs
- Security: malware, path traversal, and content sniffing

**Hands-on:** Accept a file upload, validate it, store it, and persist a reference in the database.
**You can move on when:** Your endpoint rejects oversized or wrong-type files and stores valid ones with a DB reference.

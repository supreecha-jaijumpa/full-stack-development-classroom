# 11.1 REST Deep Dive

> Module 11 — API Design & Real-Time · Phase 3

**What you'll learn:** Advanced REST conventions that make an API robust, cacheable, and easy to evolve.

- Richardson Maturity Model and HATEOAS in practice
- Content negotiation and the Accept/Content-Type headers
- Caching with ETags and conditional requests
- Idempotency keys for safe retries
- Consistent error formats (e.g. Problem Details / RFC 9457)
- Designing for backward compatibility

**Hands-on:** Add ETags, content negotiation, and a consistent error envelope to existing endpoints.
**You can move on when:** Your API supports conditional requests and returns uniform, well-structured errors.

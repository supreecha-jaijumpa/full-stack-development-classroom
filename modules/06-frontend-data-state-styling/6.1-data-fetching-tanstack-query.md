# 6.1 Data Fetching (TanStack Query)

> Module 06 — Frontend Data, State & Styling · Phase 2

**What you'll learn:** How to fetch, cache, and synchronize server data declaratively with TanStack Query instead of hand-rolled `useEffect` fetches.

- The idea of server state vs. client state and why it needs different tooling.
- `useQuery`: query keys, the fetcher function, and returned `data`/`isLoading`/`error`.
- Handling the four async states: loading, error, empty, and success.
- Caching, staleness, refetching, and background updates.
- Mutations with `useMutation` and invalidating queries to refresh data.
- Typing queries and the API response shape.

**Hands-on:** Use `useQuery` to fetch a paginated list from a public API and render distinct loading, error, and empty UIs.
**You can move on when:** You can replace a manual `useEffect` fetch with `useQuery` and explain when cached data is reused vs. refetched.

# 6.5 Component Design & Reusability

> Module 06 — Frontend Data, State & Styling · Phase 2

**What you'll learn:** How to design components with clean, reusable APIs that compose well across an application.

- Single-responsibility components and splitting presentational vs. container logic.
- Designing a clear, minimal, typed prop API.
- Composition patterns: `children`, slots, and compound components.
- Sensible defaults and controlled vs. uncontrolled component options.
- Avoiding over-abstraction — knowing when not to generalize yet.
- Building a small, consistent set of UI primitives (Button, Input, Card).

**Hands-on:** Refactor a hard-coded, one-off component into a reusable, prop-driven component used in at least two places.
**You can move on when:** You can take a duplicated piece of UI and turn it into one reusable component with a clean typed API.

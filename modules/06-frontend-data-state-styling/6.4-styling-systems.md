# 6.4 Styling Systems (Tailwind / CSS-in-JS)

> Module 06 — Frontend Data, State & Styling · Phase 2

**What you'll learn:** How to style React apps cohesively, with Tailwind as the primary approach and an understanding of the alternatives.

- The styling landscape: plain CSS, CSS modules, CSS-in-JS, and utility-first.
- Tailwind setup in a Vite project and the utility-class workflow.
- Responsive design with breakpoints, spacing scale, and design tokens.
- Composing classes conditionally (e.g. `clsx`) and extracting repeated patterns.
- Theming, dark mode, and consistency via the Tailwind config.
- Trade-offs of CSS-in-JS (runtime cost, colocation) vs. utility-first.

**Hands-on:** Style a responsive dashboard layout (sidebar + grid of cards) using Tailwind utility classes.
**You can move on when:** You can build a responsive, themed layout with Tailwind and explain when you'd choose another styling approach.

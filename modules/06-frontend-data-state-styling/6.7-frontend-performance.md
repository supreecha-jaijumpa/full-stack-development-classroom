# 6.7 Frontend Performance (memo, lazy, code-split)

> Module 06 — Frontend Data, State & Styling · Phase 2

**What you'll learn:** How to find and fix common React performance problems so the UI stays fast as it grows.

- How re-renders propagate and how to spot wasteful ones with the React DevTools Profiler.
- `React.memo` for skipping re-renders of pure components.
- `useMemo` and `useCallback` for stabilizing expensive values and callbacks.
- Code splitting with `React.lazy` and `<Suspense>`.
- Route-based splitting to shrink the initial bundle.
- Virtualization and pagination for large lists.

**Hands-on:** Lazy-load a route with `React.lazy`/`Suspense` and memoize an expensive list so it stops re-rendering needlessly.
**You can move on when:** You can use the Profiler to identify an unnecessary re-render and eliminate it, and code-split at least one route.

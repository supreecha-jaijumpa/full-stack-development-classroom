# 6.2 Global State Management

> Module 06 — Frontend Data, State & Styling · Phase 2

**What you'll learn:** How to share client state across the component tree without drilling props through every level.

- Identifying prop-drilling and when state truly needs to be global.
- React Context: creating, providing, and consuming a context value.
- Typing a context and providing a safe default / custom hook accessor.
- When Context is enough vs. when to reach for a store (Zustand/Redux).
- Keeping server state in TanStack Query and client state separate.
- Avoiding unnecessary re-renders from context value changes.

**Hands-on:** Replace prop-drilling for a theme or auth value with a typed Context and a `useTheme()`/`useAuth()` hook.
**You can move on when:** You can move a value out of props into shared state and explain why Context (not a global store) fit the case.

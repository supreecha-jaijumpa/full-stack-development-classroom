# 15.2 Backend Performance

> Module 15 — Performance & Scalability · Phase 4

**What you'll learn:** How to make your Node/Express backend handle requests faster and more efficiently.

- Finding slow endpoints with timing and request metrics
- Avoiding blocking the event loop and using async I/O well
- Reducing redundant and N+1 database queries
- Connection pooling and reusing expensive resources
- Pagination, batching, and trimming response payloads

**Hands-on:** Find and fix a slow backend endpoint by reducing blocking work or unnecessary queries.
**You can move on when:** A targeted endpoint's response time drops measurably after your change.

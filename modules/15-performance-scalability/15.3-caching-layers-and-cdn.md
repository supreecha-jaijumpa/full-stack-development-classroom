# 15.3 Caching Layers & CDN

> Module 15 — Performance & Scalability · Phase 4

**What you'll learn:** How to serve repeated and static content without recomputing or re-fetching it.

- The caching layers: browser, CDN, application, and database
- Using a CDN for static assets and edge caching
- Application caching with Redis for hot data
- Cache keys, TTLs, and invalidation on writes
- Deciding what to cache and the cost of stale data

**Hands-on:** Put a CDN in front of static assets and add a Redis cache layer to a hot path.
**You can move on when:** A repeated request is served from cache or CDN instead of recomputing.

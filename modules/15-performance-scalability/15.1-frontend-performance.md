# 15.1 Frontend Performance

> Module 15 — Performance & Scalability · Phase 4

**What you'll learn:** How to make your React frontend load and render faster for real users.

- Measuring with Lighthouse and Core Web Vitals (LCP, CLS, INP)
- Code splitting, lazy loading, and shrinking the bundle
- Memoization and avoiding unnecessary re-renders
- Optimizing images, fonts, and asset delivery
- Reducing blocking JavaScript and deferring non-critical work

**Hands-on:** Cut bundle size and improve a Core Web Vitals score with code splitting and lazy loading.
**You can move on when:** You can show a measured improvement in a Core Web Vitals metric.
